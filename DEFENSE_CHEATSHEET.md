# Шпаргалка для защиты диплома

## 🚀 Быстрый запуск

```bash
# 1. Запустить систему
./start-demo.sh

# 2. Открыть в браузере
http://localhost:3000

# 3. После демонстрации
./stop-demo.sh
```

## 📋 Сценарий демонстрации (15 минут)

### 1. Обзор (2 мин)
- Открыть главную страницу
- Показать Dashboard с миссиями
- Объяснить уровни A, B, C

### 2. Демонстрация миссии (7 мин)
- Выбрать "Создание архива" (уровень B)
- Запустить песочницу
- Выполнить команды:
  ```bash
  ls documents/
  tar -czf backup.tar.gz documents/
  tar -tzf backup.tar.gz
  ```
- Проверить выполнение
- Показать результаты

### 3. Архитектура (3 мин)
- Показать API: http://localhost:8000/docs
- Показать контейнеры: `podman ps`
- Объяснить изоляцию

### 4. Grader (3 мин)
- Показать конфигурацию: `cat missions/level_a/copy_file/mission.yaml`
- Объяснить автоматическую проверку
- Показать типы проверок

## 🎯 Ключевые технологии

- **Backend**: FastAPI (Python)
- **Frontend**: React 18
- **Контейнеризация**: Podman (rootless)
- **Проверка**: Автоматический Grader
- **Изоляция**: Linux контейнеры

## 💡 Ответы на вопросы

### Почему Podman, а не Docker?
- Rootless режим (безопаснее)
- Совместимость с Astra Linux
- Нет демона (меньше ресурсов)
- Совместим с Docker CLI

### Как обеспечивается безопасность?
- Изолированные контейнеры
- Rootless режим
- Ограничение ресурсов
- Нет доступа к хост-системе

### Как добавить новую миссию?
1. Создать YAML файл в `missions/level_X/`
2. Описать цели и проверки
3. Система автоматически подхватит

### Как система масштабируется?
- Модульная архитектура
- YAML конфигурация
- API для интеграции
- Легко добавлять уровни

## 🔧 Команды для демонстрации

### Проверка системы
```bash
podman images
podman ps
curl http://localhost:8000/api/v1/missions
```

### API примеры
```bash
# Создать песочницу
curl -X POST http://localhost:8000/api/v1/sandbox/create \
  -H "Content-Type: application/json" \
  -d '{"mission_id":"copy_file","level":"A"}'

# Проверить миссию
curl -X POST "http://localhost:8000/api/v1/grader/check/copy_file?level=A"
```

### Показать код
```bash
# Grader
cat backend/grader/checker.py

# API
cat backend/api/routes/grader.py

# Миссия
cat missions/level_a/copy_file/mission.yaml
```
