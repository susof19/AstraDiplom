## 🎯 Решённые проблемы

### 1. Автоматический запуск без разрешения

**Проблема**: TigerVNC в Astra Linux по умолчанию требует подтверждение при каждом подключении через `--QueryConnect`.

**Решение**: 
- Использование опции `--SecurityTypes None` для отключения аутентификации
- Запуск через supervisor для автоматического старта
- Предустановленный пароль через `vncpasswd`

### 2. Доступ через веб-браузер

**Проблема**: Стандартные VNC клиенты требуют установки дополнительного ПО.

**Решение**:
- Интеграция noVNC (HTML5 VNC клиент)
- websockify для проксирования WebSocket → TCP
- Встраивание через iframe в React компонент

### 3. Изоляция и безопасность

**Проблема**: VNC должен быть доступен только для конкретной миссии.

**Решение**:
- Каждый контейнер использует уникальные порты
- Динамическое выделение портов через `_find_free_port()`
- Rootless режим Podman для изоляции

## 🚀 Использование

### Сборка образа

```bash
cd scripts
./build-astra-vnc-image.sh
```

### Тестовый запуск

```bash
podman run -d \
    --name astra-vnc-test \
    -p 5900:5900 \
    -p 6080:6080 \
    localhost/astra-linux:vnc
```

### Подключение

Откройте в браузере: `http://localhost:6080/vnc.html`

### Использование в проекте

Backend автоматически использует VNC образ для миссий уровня A:

```python
# Создание песочницы с VNC
sandbox = await sandbox_manager.create_sandbox(
    mission_id="change_wallpaper",
    level="A",
    use_vnc=True  # По умолчанию
)

# Получение URL для подключения
vnc_url = await sandbox.get_vnc_url()
# Результат: "http://localhost:6080/vnc.html"
```

Frontend автоматически отображает VNC для миссий с GUI:

```jsx
<SandboxViewer missionId="change_wallpaper" level="A" />
```

## 🔧 Конфигурация

### Настройки по умолчанию

```python
# backend/config.py
VNC_PORT_START: int = 5900        # Начальный порт для VNC
NOVNC_PORT_START: int = 6080      # Начальный порт для noVNC
VNC_PASSWORD: str = "astra123"    # Пароль VNC
VNC_RESOLUTION: str = "1280x720"  # Разрешение экрана
```

### Переменные окружения контейнера

```bash
DISPLAY=:0                    # X11 дисплей
VNC_PORT=5900                 # Порт VNC
NOVNC_PORT=6080               # Порт noVNC
VNC_RESOLUTION=1280x720       # Разрешение
VNC_DEPTH=24                  # Глубина цвета
```
