# Руководство администратора

Руководство по использованию панели администратора для управления миссиями.

## Настройка

### 1. Добавление поля is_admin в базу данных

Если база данных уже создана, выполните миграцию:

```bash
cd backend
source venv/bin/activate
python ../scripts/add-admin-field.py
```

### 2. Назначение пользователя администратором

```bash
cd backend
source venv/bin/activate
python ../scripts/make-admin.py <username>
```

Например:
```bash
python ../scripts/make-admin.py admin
```

### 3. Доступ к панели администратора

После назначения прав администратора:
1. Войдите в систему под учетной записью администратора
2. В боковом меню появится пункт "⚙️ Администрирование"
3. Перейдите в панель администратора

## Управление миссиями

### Создание новой миссии

1. Нажмите кнопку "➕ Создать миссию"
2. Заполните форму:
   - **ID миссии**: уникальный идентификатор (например, `my_new_mission`)
   - **Уровень**: A (новички) или B (продвинутые)
   - **Название**: название миссии
   - **Описание**: описание миссии
   - **Сложность**: от 1 до 5 звезд
   - **Время**: примерное время выполнения в минутах
   - **Цели**: JSON массив строк с целями миссии
   - **Подсказки**: JSON массив строк с подсказками (опционально)
   - **Проверки**: JSON массив объектов с проверками
   - **Настройка**: JSON объект с настройками (опционально)

3. Нажмите "Создать"

### Редактирование миссии

1. В таблице миссий нажмите "✏️ Редактировать"
2. Измените нужные поля
3. Нажмите "Сохранить"

### Удаление миссии

1. В таблице миссий нажмите "🗑️ Удалить"
2. Подтвердите удаление

⚠️ **Внимание**: Удаление миссии необратимо!

## Формат данных миссий

### Цели (objectives)

JSON массив строк:
```json
[
  "Открыть файловый менеджер",
  "Перейти в папку Документы",
  "Создать новую папку с именем «Проект»"
]
```

### Подсказки (hints)

JSON массив строк:
```json
[
  "Файловый менеджер можно открыть через Меню → Файловый менеджер",
  "Или дважды кликните на иконку 'Домашняя папка' на рабочем столе"
]
```

### Проверки (checks)

JSON массив объектов. Каждый объект содержит:
- `name`: название проверки
- `type`: тип проверки (например, `file_exists`, `command_output`)
- `path` или другие параметры в зависимости от типа
- `points`: количество баллов за проверку

Пример:
```json
[
  {
    "name": "Папка Проект создана",
    "type": "file_exists",
    "path": "/root/Documents/Проект",
    "file_type": "directory",
    "points": 100
  }
]
```

### Настройка (setup)

JSON объект с настройками для подготовки окружения:
```json
{
  "directories": [
    "/root/Documents"
  ],
  "files": [
    {
      "path": "/root/example.txt",
      "content": "Пример содержимого"
    }
  ]
}
```

## Пример полной конфигурации миссии

```yaml
name: "Создать папку в Документах"
description: "Откройте файловый менеджер, перейдите в «Документы» и создайте новую папку с именем «Проект»"
level: "A"
difficulty: 1
estimated_time: 3

objectives:
  - "Открыть файловый менеджер"
  - "Перейти в папку Документы"
  - "Создать новую папку с именем «Проект»"

hints:
  - "Файловый менеджер можно открыть через Меню → Файловый менеджер"
  - "Или дважды кликните на иконку 'Домашняя папка' на рабочем столе"

setup:
  directories:
    - "/root/Documents"

checks:
  - name: "Папка Проект создана"
    type: "file_exists"
    path: "/root/Documents/Проект"
    file_type: "directory"
    points: 100
```

## Безопасность

- Только пользователи с правами администратора могут управлять миссиями
- Все действия логируются в backend
- При обновлении миссии создается резервная копия

## Устранение проблем

### Пользователь не видит панель администратора

1. Проверьте, что пользователь назначен администратором:
   ```bash
   python scripts/make-admin.py <username>
   ```

2. Выйдите и войдите в систему заново

3. Проверьте, что поле is_admin добавлено в базу данных:
   ```bash
   python scripts/add-admin-field.py
   ```

### Ошибка при создании миссии

1. Проверьте формат JSON в полях "Цели", "Подсказки", "Проверки"
2. Убедитесь, что ID миссии уникален
3. Проверьте логи backend для детальной информации об ошибке
