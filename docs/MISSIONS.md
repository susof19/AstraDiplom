# Руководство по созданию миссий

## Структура миссии

Каждая миссия находится в директории:
```
missions/level_a/{mission_id}/
├── mission.yaml      # Конфигурация миссии
└── assets/           # Дополнительные файлы (опционально)
```

## Формат mission.yaml

### Базовые поля

```yaml
name: "Название миссии"           # Обязательно
description: "Описание задания"   # Обязательно
level: "A"                        # Уровень A (GUI-миссии)
difficulty: 1                     # 1-5
estimated_time: 10                # Минуты
```

### Objectives (Цели)

Список целей, которые должен выполнить пользователь:

```yaml
objectives:
  - "Цель 1"
  - "Цель 2"
```

### Hints (Подсказки)

Подсказки для пользователя:

```yaml
hints:
  - "Подсказка 1"
  - "Подсказка 2"
```

### Checks (Проверки)

Список проверок для grader'а:

```yaml
checks:
  - name: "Название проверки"
    type: "file_exists"           # Тип проверки
    path: "/path/to/file"         # Параметры
    points: 50                    # Баллы
```

## Типы проверок

### file_exists

Проверяет существование файла или директории:

```yaml
- name: "Файл создан"
  type: "file_exists"
  path: "/home/user/file.txt"
  points: 100
```

### file_content

Проверяет содержимое файла:

```yaml
- name: "Файл содержит текст"
  type: "file_content"
  path: "/home/user/config.txt"
  expected: "key=value"
  points: 50
```

### command_output

Проверяет вывод команды:

```yaml
- name: "Команда выполнена"
  type: "command_output"
  command: "ls /home/user"
  expected: "file.txt"
  points: 50
```

### gui_state

Проверяет состояние GUI:

```yaml
- name: "Окно открыто"
  type: "gui_state"
  window: "gedit"
  points: 50
```

## Примеры миссий

### Уровень A: Копирование файла

```yaml
name: "Копирование файла с USB"
description: "Скопируйте файл photo.jpg с USB в папку Документы"
level: "A"
difficulty: 1
estimated_time: 5

objectives:
  - "Подключить USB-накопитель"
  - "Найти файл photo.jpg"
  - "Скопировать файл в папку Документы"

hints:
  - "Используйте файловый менеджер"
  - "USB обычно монтируется в /media"

checks:
  - name: "Файл скопирован"
    type: "file_exists"
    path: "/home/user/Документы/photo.jpg"
    points: 100
```

## Рекомендации

1. **Чёткие цели**: Objectives должны быть конкретными и измеримыми
2. **Полезные подсказки**: Hints должны направлять, но не давать прямого ответа
3. **Множественные проверки**: Используйте несколько checks для разных аспектов задания
4. **Реалистичные задания**: Миссии должны отражать реальные сценарии работы
5. **Прогрессивная сложность**: Начинайте с простых заданий и усложняйте

## Тестирование миссии

1. Создайте миссию в соответствующей директории
2. Запустите backend и frontend
3. Откройте миссию в интерфейсе
4. Запустите песочницу
5. Выполните задание
6. Проверьте работу grader'а
7. Убедитесь, что все checks работают корректно
